A **hole** is a set of Petra's modes taken as discharged, the verdict of a deck that lacks those checks. A design **exposes** it when the holed Petra passes it, the judge rejects it for a condition the hole guards, and Petra itself does not pass it (or the hole has no modes, because today's Petra already lacks the check). **Recall** is holes exposed over holes planted, per kind and domain, with the generator drawing 600 designs of each kind from seed 2's stream and the steel breaker climbing 600 Petra evaluations on each steel hole the generator missed. `scripts/canary_recall.py` says how the holes are chosen.

## Recall per kind and domain

**Canary holes** guard a canary's condition with the modes that refuse that canary today; P1's predicate reads this column. **Mode holes** take out one mode Petra checks on the kind and count a find under any condition the judge raises: the judge has no condition of its own for these modes, so a find needs a design it rejects for another reason that passes everything but the mode.
