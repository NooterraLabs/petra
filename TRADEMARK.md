# The Petra name

Nooterra holds the name Petra for this checker and its `.petra` language. This policy says how anyone may use the name. It is a draft. It opens for public comment when the repository goes public, and it changes only after that comment.

## Use it freely, without asking

- Say that software reads, writes or works with `.petra` files, or that it is compatible with Petra.
- Name Petra in articles, talks, papers, courses, benchmark results and comparisons.
- Name a package, plugin or repository that works with Petra `petra-something` or `something-petra`, as long as it does not claim to be official.
- Fork the code. A fork may say it is based on Petra, but it ships under a name of its own.

## Reserved

- **"Petra-checked"**, and wording such as "checked by Petra", is a claim about a verdict. A verdict may carry it only if it came from a checker that passes the Petra conformance corpus at the version the verdict names, and the verdict names that checker and version. Until the conformance corpus is published, only released versions of this repository's checker qualify.
- **Official standing.** No product, service or company may use the name to suggest that Nooterra or the Petra project made or endorses it, for example "Official Petra" or a company named after Petra, without written permission.

## Why "Petra-checked" is reserved

A verdict is worth only as much as the check behind it. If any tool could print "Petra-checked", the words would stop meaning a fixed set of checks. The conformance corpus is a public set of valid certificates and certificates with planted faults. It lets anyone build an independent checker and earn the words by passing it, without asking Nooterra. [docs/open_source.md](docs/open_source.md) gives the precedents.
