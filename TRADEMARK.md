# The Petra name

Nooterra uses the name Petra for this checker and its `.petra` language. This policy covers that use only, and claims nothing over other products called Petra. It is a draft. To comment on it, open an issue.

## Uses that need no permission

- Say that software reads, writes or works with `.petra` files, or that it is compatible with Petra.
- Name Petra in articles, talks, papers, courses, benchmark results and comparisons.
- Name a package, plugin or repository that works with Petra `petra-something` or `something-petra`, as long as it does not claim to be official.
- Fork the code. A fork may say it is based on Petra, but it ships under its own name.

## Reserved uses

- "Petra-checked", and wording such as "checked by Petra", is a claim about a verdict. A verdict may carry it only if it came from a checker that passes the Petra conformance corpus at the version the verdict names, and the verdict names that checker and version. Until the corpus is published, only released versions of this repository's checker qualify.
- No product, service or company may use the name to suggest that Nooterra or the Petra project made or endorses it, for example "Official Petra" or a company named after Petra, without written permission.

## Why "Petra-checked" is reserved

"Petra-checked" tells a reader which checks a verdict passed. If any tool could print it, the words would no longer name a fixed set of checks. The conformance corpus will be a public set of valid certificates and certificates with planted faults. Anyone can build an independent checker and earn the words by passing the corpus, without asking Nooterra. [docs/open_source.md](docs/open_source.md) gives the precedents.
